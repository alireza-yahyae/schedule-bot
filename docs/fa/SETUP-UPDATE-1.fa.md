# به‌روزرسانی ۱: دسته‌بندی فعالیت (درس / کار / دلخواه)

دیتابیس، رمزها و webhook همون‌ها می‌مونن. فقط فایل‌های جدید رو جایگزین می‌کنی.

## ۱) جایگزین کردن فایل‌ها
1. فایل zip جدید رو Extract کن.
2. همه‌ی چیزهای داخل پوشه‌ی `schedule-bot` رو کپی کن و توی `E:\schedule-bot` Paste کن (Replace the files).
3. `node_modules` رو دست نزن.

## ۲) ساخت جدول جدید
```powershell
npx wrangler d1 migrations apply schedule-bot-db --remote
```
وقتی پرسید `y` بزن. **باید ببینی:** یه ✅ کنار `0007_categories.sql`.

## ۳) آپلود
```powershell
npx wrangler deploy
```

## ۴) تست
1. برنامه رو از تلگرام باز کن (`/app`). توی کارت امروز باید چیپ‌های «📚 درس»، «💼 کار»، «🛠 پروژه شخصی» ببینی.
2. «کار» رو انتخاب کن و «شروع کار» رو بزن. بالای کارت اسم «💼 کار» میاد. بعد «تموم شد» رو بزن.
3. زیر عدد کل، تفکیک ساعت هر دسته نشون داده می‌شه.
4. دکمه‌ی ⚙️ کنار «ثبت دستی»: دسته‌ی جدید بساز، ویرایش کن یا بایگانی کن.
5. توی ربات `/work 90` رو بزن (۹۰ دقیقه کار ثبت می‌شه). بعد از `/start` دوباره، `/work` توی منوی دستورها هم میاد.

## چی عوض شد
- تایمر، «قبلاً شروع کردم» و «ثبت دستی» حالا دسته می‌گیرن. دسته‌ی آخرین جلسه پیش‌فرض می‌شه.
- جلسه‌های قدیمی خودکار می‌رن توی «درس».
- دسته‌ی «درس» حذف‌شدنی نیست. دسته‌ای که جلسه داره حذف نمی‌شه و بایگانی می‌شه، که آمار قبلی نپره. حداکثر ۱۲ دسته‌ی فعال.

## یه نکته
فعلاً **همه‌ی دسته‌ها** توی «ساعت امروز»، پیام‌های «بیکاری» پارتنر و چالش روزانه حساب می‌شن (یعنی وقتی کار می‌کنی، بیکار حساب نمی‌شی). جدا کردن هدف و چالش برای هر دسته مرحله ۳ هست.
