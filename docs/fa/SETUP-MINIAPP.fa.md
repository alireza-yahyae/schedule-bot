# به‌روزرسانی: اضافه شدن Mini App (برنامه‌ی داخل تلگرام)

این نسخه فقط چیزهای جدید رو به پروژه‌ی فعلی‌ات اضافه می‌کنه. دیتابیس، رمزها و webhook همون‌ها می‌مونن.
`wrangler.toml` توی این نسخه از قبل با `database_id` و آدرس ربات خودت پر شده؛ لازم نیست دستی عوضش کنی.

## ۱) جایگزین کردن فایل‌ها
1. فایل zip جدید رو باز کن (Extract All).
2. همه‌ی چیزهای داخل پوشه‌ی `schedule-bot` رو **کپی** کن و توی `E:\schedule-bot` **Paste** کن.
3. وقتی ویندوز پرسید، **Replace the files in the destination** رو بزن.
4. پوشه‌ی `node_modules` رو دست نزن. نیازی به `npm install` دوباره نیست.

## ۲) ساخت جدول‌های جدید (کارها، تمرکز)
PowerShell رو توی `E:\schedule-bot` باز کن و بزن:
```powershell
npx wrangler d1 migrations apply schedule-bot-db --remote
```
وقتی پرسید `y` بزن. **باید ببینی:** یه ✅ کنار `0003_miniapp.sql`.

## ۳) فونت وزیرمتن (اختیاری ولی قشنگ‌تر)
```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\get-font.ps1
```
**باید ببینی:** `OK: font saved to ...`. اگه دانلود نشد، مشکلی نیست؛ برنامه با فونت سیستم هم کار می‌کنه.

## ۴) آپلود
```powershell
npx wrangler deploy
```
**باید ببینی:** خط‌هایی مثل `Uploaded schedule-bot` و `https://schedule-bot.YOUR-NAME.workers.dev`. توی خروجی اسم فایل‌های `public` هم میاد.

## ۵) باز کردن برنامه
1. تو ربات تلگرام `/start` بزن. یه دکمه‌ی **📱 باز کردن برنامه** میاد، و کنار جای تایپ هم دکمه‌ی **برنامه** ساخته می‌شه.
2. دکمه رو بزن. بار اول یه راهنمای ۵ مرحله‌ای (منطقه‌ی زمانی، ساعت‌های غذا و خواب، ...) میاد؛ می‌تونی «رد کردن» بزنی.
3. اگه دکمه‌ها نیومد، فقط `/app` بزن.

## چی توی برنامه هست
- **امروز:** کلاس بعدی با شمارش معکوس زنده، حلقه‌ی پیشرفت روز، دکمه‌های رفتم / برگزار نشد / نمی‌رم، خط زمانی روز، کارهای نزدیک، تایمر تمرکز (پومودورو).
- **هفته:** جدول هفتگی رنگی با هشدار تداخل (روی درس بزن = جزئیات، نگه دار = ویرایش)، لیست درس‌ها، امتحان‌ها با شمارش معکوس، کارها و موعدها.
- **پیام‌ها:** اتصال پارتنر، ثبت مطالعه، ارسال سریع پیام (با پیش‌نمایش و ویرایش قبل از ارسال) و مدیریت متن پیام‌ها (جزئیات پایین، بخش «مرحله‌ی ۲»).
- **پیشرفت:** عادت‌ها (تیک روزانه و رکورد پشت‌سرهم) و نمره‌ها (معدل ترم و کل).
- **آمار:** درصد حضور، رکورد پشت‌سرهم رفتن، غیبت هر درس نسبت به سقف مجاز، نمودار هفتگی، دقیقه‌های تمرکز، دلیل‌های نرفتن.
- **تنظیمات:** ارقام فارسی/لاتین، منطقه‌ی زمانی، یادآوری‌ها، ساعت‌های روزانه، حالت تعطیلات، توقف موقت، ویرایش همه‌ی متن‌های ربات، آموزش.
- هر کاری رو با «برگردان» (توی پیام پایین صفحه) می‌تونی پس بگیری.
- اضافه کردن «درس جدید» با دکمه‌ی + (روز و ساعت جلسه‌ها، تاریخ امتحان شمسی، رنگ، غیبت مجاز و ...).

## اشتباه‌های رایج
| مشکل | راه‌حل |
|---|---|
| برنامه می‌گه «لطفاً از داخل تلگرام باز کن» | آدرس رو توی مرورگر باز کردی. از دکمه‌ی داخل ربات (`/app`) باز کن |
| «نشست منقضی شده» | برنامه رو ببند و دوباره از ربات باز کن |
| صفحه سفید یا خطای ۴۰۴ | `npx wrangler deploy` رو دوباره بزن و مطمئن شو پوشه‌ی `public` کنار `wrangler.toml` هست |
| درس‌ها یا کارها ذخیره نمی‌شه | مرحله‌ی ۲ (migration شماره ۰۰۰۳) رو انجام نداده‌ای |
| «جدول‌های مرحله‌ی ۲ ساخته نشدن» یا پیام‌ها/پیشرفت خطا می‌ده | migration شماره ۰۰۰۴ رو اجرا نکرده‌ای (`npm run db:migrate`) |
| فونت عجیبه | مرحله‌ی ۳ رو انجام بده، بعد برنامه رو کامل ببند و دوباره باز کن |
| بعد از آپدیت چیزی عوض نشد | برنامه رو کامل ببند و دوباره باز کن (کش تلگرام) |

## مرحله‌ی ۲: پارتنر، عادت‌ها و نمره‌ها
**نصب (یک بار):**
```
npm run db:migrate
npx wrangler deploy
```
باید یه ✅ کنار `0004_phase2_features.sql` ببینی. این migration فقط جدول‌های تازه می‌سازه و به داده‌های قبلی دست نمی‌زنه.

**وصل کردن پارتنر:**
1. توی برنامه برو تب **پیام‌ها** و **ارسال لینک دعوت** رو بزن (یا کد ۸ حرفی رو بده).
2. پارتنرت لینک رو باز می‌کنه و **Start** می‌زنه (یا توی چت ربات `/pair کد` می‌فرسته). کد فقط یک بار کار می‌کنه.
3. از اون لحظه اسمش بالای صفحه میاد. هر وقت خواست با `/stop` خارج می‌شه، یا خودت «قطع اتصال» رو بزن.

**پارتنر چی می‌بینه؟** فقط صفحه‌ی «متن پیام‌ها» (اگه اجازه بدی ویرایش و اضافه کنه). به درس‌ها، کارها و تنظیمات تو هیچ دسترسی نداره.

**دستورهای تازه‌ی ربات:** `/study 90` (ثبت ۹۰ دقیقه مطالعه)، `/slacking`، `/studied`، `/remind_partner`.

**پیام خودکار** (با کلید «پیام خودکار» قابل خاموش کردنه): اگه از آخرین مطالعه‌ات به اندازه‌ی «حساسیت بیکاری» گذشته باشه (فقط بین ساعت ۹ تا ۲۲، و وسط کلاس نه) یه پیام به پارتنر می‌ره؛ هر ۲ ساعت حداکثر یکی. وقتی امروز به «حد نصاب خرخونی» رسیدی، یه پیام تشویقی (روزی یک بار) می‌ره. یه پیام صبح (۸ تا ۸:۳۰) و یکی شب (۲۳ تا ۲۳:۳۰) هم هست. حالت تعطیلات و «توقف موقت» همه‌ی این‌ها رو ساکت می‌کنن. زمان‌های تمرکز (پومودورو) هم جزو مطالعه حساب می‌شن.

**متن پیام‌ها:** `{hours}` جای تعداد ساعت و `{partner}` جای اسم پارتنر می‌شینه. پیام‌های «یادآوری برای پارتنر» ساعت نمی‌گیرن، چون ربات نمی‌دونه پارتنرت چقدر درس خونده.

**هفته ← چسباندن برنامه از متن / خروجی:** هر خط یه درس، مثلاً `شنبه و سه‌شنبه 08:00-10:00 ریاضی ۲`. خروجی CSV و تقویم (ICS) هم همون‌جاست. بعضی نسخه‌های تلگرام دانلود فایل رو بلاک می‌کنن؛ اون‌وقت از دکمه‌ی «کپی متن» استفاده کن.

## روزهای خاص (خواب متفاوت و خاموشی)
**اجرا:** بعد از آپدیت یک بار `npm run db:migrate` و `npx wrangler deploy` (فایل `0005_day_overrides.sql` فقط یه جدول تازه می‌سازه).

**چطور؟** توی تب «امروز» دکمه‌ی 🌙 بالای صفحه رو بزن (یا تنظیمات ← «روزهای خاص» ← «افزودن»). انتخاب کن برای **امروز**، **فردا** یا **هر هفته** (مثلاً همه‌ی شنبه‌ها) باشه، و بعد:
- **ساعت خواب / بیدار شدن** رو برای اون روز عوض کن. توی خط زمانی امروز نشون داده می‌شه و پیام خودکار صبح/شب پارتنر هم باهاش جابه‌جا می‌شه. خوابِ بعد از نیمه‌شب (مثلاً ۰۱:۳۰) هم درسته.
- **خاموشی:** «کل روز» یعنی اون روز هیچ یادآوری‌ای نمیاد؛ «یه بازه» یعنی فقط بین دو ساعت (مثلاً ۱۴ تا ۱۶) ساکته. بازه‌ای که از نیمه‌شب رد بشه هم پشتیبانی می‌شه. خاموشی مثل «توقف موقت» عمل می‌کنه: کلاس‌هایی که وسطش باشن بدون پیام می‌گذرن.

**اولویت:** تنظیمِ همون تاریخ > تنظیم هفتگی > تنظیمات عادی. قانون‌های یک‌باره‌ی روزهای گذشته خودشون پاک می‌شن.

## نسخه‌ی ۵: تایمر درس خوندن، چالش، پیام‌های پارتنر
**اجرا:** `python deploy_schedule_bot.py` یا دستی `npm run db:migrate` و بعد `npm run deploy`.
⚠️ فایل `0006_daily_rhythm.sql` ساعت‌های عادی رو روی **خواب ۰۷:۰۰ و بیدار شدن ۱۲:۰۰** می‌ذاره (طبق گفته‌ی خودت). هر وقت خواستی از تنظیمات عوضشون کن؛ برای روزهای خاص هم «روزهای خاص» هست.

**«روز» تو از بیدار شدن شروع می‌شه و تا خواب ادامه داره** (حتی بعد از نیمه‌شب). سلام اپ، ساعت‌های درس خوندن، چالش و بیکاری همه با همین حساب می‌شن، نه با ساعت دیوار.

**امروز:**
- **درس خوندن:** «شروع درس خوندن» رو که زدی تایمر روشن می‌مونه حتی اگه اپ رو ببندی. هر وقت تموم شد «تموم شد» رو بزن؛ می‌تونی بگی وسطش چند دقیقه استراحت یا کار اضافه کردی تا کم بشه. «قبلاً شروع کردم…» برای وقتی که یادت رفته بود، و «ثبت دستی» با ساعت شروع و پایان.
- **کلاس و درس:** بالای کارت، زمان کلاس‌هایی که رفتی کنار زمان درس خوندن دیده می‌شه.
- **ناهار و شام:** روی خط زمانی «خوردم» بزن، یا «بعداً…» با گزینه‌ی «بعد از شام» یا «بعد از بیدار شدن». بیدار شدن همیشه اول و خواب همیشه آخره.
- **چالش پارتنر:** اگه پارتنرت برای امروز چالش گذاشته باشه، توی همین صفحه با نوار پیشرفت می‌بینی.
- کارت «برنامه‌ات کامله؟» حالا کوچیک و بسته توی تنظیمات هست.

**اپ پارتنر (جدا و با ظاهر خودش):** خانه (وضعیت درس خوندنت)، پیام (خودش می‌نویسه و می‌فرسته، فوری یا زمان‌بندی‌شده، با پیام‌های آماده‌ی شخصی)، چالش (جایزه و تنبیه برای امروز یا فردا)، متن‌ها (متن پیام‌های خودکار ربات).
- پیام‌هایی که اون برات می‌نویسه **توی اپ تو نشون داده نمی‌شن**؛ فقط توی تلگرام بهت می‌رسن (بی‌صدا اگه خوابی یا خاموشی داری).
- از «پیام‌ها» می‌تونی تعیین کنی اون چی ببینه: وضعیت درس خوندن، کلاس‌های امروز؛ و بتونه پیام بفرسته یا نه.

**چالش:** پارتنر ساعت هدف + جایزه، و حداقل ساعت + تنبیه می‌نویسه. به تو خبر می‌رسه. موقع خوابت حساب می‌شه و نتیجه برای هر دوتون می‌آد.
