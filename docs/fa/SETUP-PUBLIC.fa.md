# به‌روزرسانی ۷: پابلیک کردن ربات (چندکاربره)، پرامپت هوش مصنوعی، «👍 باشه» و رفع باگ‌ها

بعد از این آپدیت هر کسی که توی تلگرام `/start` بزنه یه فضای کاملاً جدا برای خودش داره. **تو (مالک ربات) روی دیتابیس قبلی خودت می‌مونی** و هیچ داده‌ای جابه‌جا نمی‌شه.

## ۱) جایگزین کردن فایل‌ها
zip رو Extract کن و محتوای پوشه‌ی `schedule-bot` رو روی `E:\schedule-bot` کپی کن (Replace). `node_modules` رو دست نزن. فایل `wrangler.toml` شامل آدرس و شناسه‌ی دیتابیس خودته، پس همون رو جایگزین کن.

## ۲) migration (دو فایل جدید: `0012` و `0013`)
```powershell
npx wrangler d1 migrations apply schedule-bot-db --remote
```

## ۳) آپلود
```powershell
npm run deploy
```
(این دستور اول فایل ساخت دیتابیسِ هر کاربر رو از روی migrationها دوباره می‌سازه و بعد آپلود می‌کنه.) بار اول توی خروجی می‌بینی که یه چیز جدید («Durable Object: Tenant») ساخته می‌شه؛ طبیعیه.

اگه `npm run deploy` به‌خاطر نصب‌نبودن چیزی خطا داد، یه بار `npm install` بزن.

## ۴) تست (با یه اکانت تلگرام دیگه، یا از یه دوست بخواه)
1. `https://schedule-bot.YOUR-NAME.workers.dev/health` رو باز کن. باید `"ok": true` و `"users": 0` ببینی.
2. با اکانت دوم به ربات `/start` بزن. باید پیام خوش‌آمد و دکمه‌ی برنامه بیاد.
3. برنامه رو باز کن: اولین صفحه «برنامه‌ات رو بساز ✨» هست (پرامپت، فرمت، جای چسباندن). «بعداً» رو بزن، بعد سؤال‌های کوتاه (منطقه‌ی زمانی و ...) میاد. بعد از اون دیگه این صفحه خودکار نشون داده نمی‌شه.
4. توی «هفته» ← «با هوش مصنوعی / چسباندن» یا «افزودن درس» ← «✨ چند درس یکجا با هوش مصنوعی»، همین صفحه دوباره باز می‌شه.
5. یه کلاس ۱۰ دقیقه‌ی بعد بساز و ببین یادآوری میاد.
6. اگه لازم شد، لاگ زنده: `npx wrangler tail`

## چی عوض شد

### ربات چندکاربره
- هر نفر یه دیتابیس خصوصی جدا داره (Durable Object با SQLite). برنامه، عادت‌ها، آمار، پارتنر و تنظیمات هیچ‌کدوم بین آدم‌ها مشترک نیست و هر کسی با «برنامه‌ی نمونه»ی خالی شروع می‌کنه (درس‌های خودت به اون‌ها نمی‌رسه).
- پارتنر: لینک دعوت هر نفر شناسه‌ی خودش رو داره (`pair_<id>_<code>`)، پس پارتنر به آدم درست وصل می‌شه. لینک دعوتی که قبلاً برای خودت ساخته بودی همچنان کار می‌کنه.
- **ظرفیت:** پیش‌فرض ۲۰ نفر (`MAX_USERS` توی `wrangler.toml`). دلیل: هر نفر هر دقیقه حدود ۱۵۰ ردیف دیتابیس می‌خونه (چک یادآوری)، یعنی حدود ۲۰۰ هزار ردیف در روز، و پلن رایگان کلادفلر روزی ۵ میلیون ردیف اجازه می‌ده. نفر بیست‌ویکم پیام «ظرفیت پر است» می‌گیره. برای بیشتر، پلن Workers Paid (حدود ۵ دلار در ماه) بگیر و عدد رو بالا ببر.
- **حذف اطلاعات:** هر کاربر با `/delete_me` (با تأیید) همه‌ی داده‌هاش رو پاک می‌کنه.
- **ادمین:** فقط تو، با `/users` تعداد کاربرها رو می‌بینی. (حریم خصوصی: ادمین از نظر فنی به سرور دسترسی داره؛ پیام خوش‌آمد همین رو به کاربر می‌گه.)

### صفحه‌ی اول با پرامپت هوش مصنوعی
- «📋 کپی پرامپت» ← بده به ChatGPT / Gemini / Claude همراه برنامه‌ی متنی، عکس یا PDF ← جوابش رو بچسبون ← «تأیید و ساخت برنامه».
- مثالِ فرمت همیشه بالای صفحه ثابت می‌مونه (موقع تایپ هم نمی‌پره)، پس خودت هم می‌تونی با دست بنویسی.
- برنامه‌ی کاری هم پشتیبانی می‌شه: اول خط «کار:» (یا `[کار]` هرجای خط).
- اگه جای کلاس رو آخر اسم تو پرانتز بنویسی، پرانتز بسته حفظ می‌شه (یه باگ قدیمی پارسر بود).

### «👍 باشه» روی یادآوری
- بعد از زدن «باشه»: یادآوری‌های بعدیِ همون کلاس نمیاد، سؤال «رفتی؟» و نگ‌ها هم نمیاد.
- فقط یه پیام ساده‌ی «⏰ … شروع شد؛ موفق باشی» موقع شروع می‌فرسته (بدون دکمه). از تنظیمات ← یادآوری‌ها ← «بعد از زدن باشه» خاموشش می‌کنی.
- وقتی کلاس تموم شد، به‌صورت «رفتم» ثبت می‌شه (اگه اشتباه بود از برنامه عوضش کن).
- «رفتم» و «نمی‌رم» مثل قبل کار می‌کنن.

### باگ‌های عکس‌ها
- دکمه‌ی گرد «+» توی صفحه‌ی عادت‌ها وسط صفحه می‌چسبید و روی کارت می‌افتاد. علت: انیمیشن ورود صفحه، موقعیت «ثابت» رو نسبت به خودش حساب می‌کرد. درست شد و دکمه همیشه پایین صفحه‌ست.
- دکمه‌ی «+» آخرین خط (راهنمای هفته) رو می‌پوشوند؛ حالا پایین صفحه جا باز می‌شه.
- توی تنظیمات، برچسب «منطقه‌ی زمانی» دو خطی می‌شد؛ حالا برچسب بالا و انتخاب‌گر زیرشه.
- «چسباندن از من» توی عکس: متن توی کد «چسباندن از متن» بود و از بالا بریده شده بود؛ اسم دکمه هم الان «با هوش مصنوعی / چسباندن» شد.
- دست نزدم: جدول هفته با ۷ روز افقی اسکرول می‌خوره (۳ روز اول دیده می‌شه) و ترتیب + و − توی انتخاب‌گر تعداد.

## چیزهایی که خودت باید بعد از آپلود بررسی کنی
من این بخش رو روی Cloudflare واقعی نتونستم اجرا کنم. منطق رو با یه شبیه‌ساز دیتابیس و ربات ساختگی تست کردم (ثبت‌نام، جدابودن داده‌ها، پارتنر، حذف، ظرفیت، یادآوری)، ولی سه چیز فقط روی خود Cloudflare معلوم می‌شه: (۱) Durable Object با SQLite روی حساب تو فعاله، (۲) دستورهای SQL با `?1` توی اون دیتابیس درست اجرا می‌شن، (۳) محدودیت درخواست‌ها بین Worker و Durable Object. اگه توی تست بالا چیزی کار نکرد، خروجی `npx wrangler tail` رو برام بفرست.

## هنوز نیست
- مسدود کردن کاربر مزاحم از داخل ربات (فعلاً فقط با ویرایش جدول `users` توی D1).
- صفحه‌ی قوانین و حریم خصوصی کامل (فقط یه پاراگراف توی پیام خوش‌آمد هست).
- بازگردوندن بکاپ با دکمه.
