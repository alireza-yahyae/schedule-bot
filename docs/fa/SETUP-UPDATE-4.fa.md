# به‌روزرسانی ۴: برنامه‌ی کاری، تسک با تایمر، تسک تکراری

این آپدیت **یه migration جدید داره** (`0009`).

## ۱) جایگزین کردن فایل‌ها
فایل zip رو Extract کن و محتوای پوشه‌ی `schedule-bot` رو روی `E:\schedule-bot` کپی کن (Replace). `node_modules` رو دست نزن.

## ۲) migration و آپلود
```powershell
npx wrangler d1 migrations apply schedule-bot-db --remote
npx wrangler deploy
```
باید ✅ کنار `0009_work_and_tasks.sql` ببینی.

## ۳) تست
1. **برنامه‌ی کاری:** تب «برنامه» ← «برنامه‌ی کاری» (یا «افزودن درس» و بعد بالای فرم «💼 کار» رو بزن). اسم، مکان، رنگ و جلسه‌های هفتگی (مثلاً شنبه ۹ تا ۱۳) رو بنویس. گروه، واحد، استاد و امتحان برای کار نمیاد.
   - مثل کلاس‌ها یادآوری می‌گیره و تداخل با کلاس‌ها هم همون‌جور هشدار داده می‌شه.
   - تو پیام‌های ربات به‌جای «کلاس» می‌نویسه «کار» (مثلاً «الان وقت کاره!»).
   - توی آمار حضور و غیاب کلاس‌ها و سقف غیبت حساب نمی‌شه.
   - توی صفحه‌ی پارتنر عنوان کارت شده «📅 برنامه‌ی امروزش».
2. **تسک با دسته و تخمین:** توی فرم کار جدید یه دسته (درس، کار، ...)، «تخمین زمان (دقیقه)» و «تکرار» داری. توی لیست، کنار هر کار دسته و «⏱ ۱:۱۵ از ۲ ساعت» (زمان واقعی از تخمین) رو می‌بینی. اگه از تخمین بیشتر بشه قرمز می‌شه.
3. **تایمر روی تسک:** دکمه‌ی ▶ کنار هر کار، تایمر رو روی همون کار روشن می‌کنه (دسته‌ی خود کار انتخاب می‌شه). موقع اجرا، اسم کار بالای تایمر دیده می‌شه، و زمان به حساب اون کار ثبت می‌شه.
4. **یادداشت جلسه:** موقع «تموم شد» یه کادر «یادداشت» داری. توی «همه‌ی جلسه‌ها» زیر هر جلسه نشون داده می‌شه و موقع ویرایش جلسه هم قابل تغییره.
5. **تسک تکراری:** برای کار تکراری موعد لازمه. وقتی تیکش رو می‌زنی، نسخه‌ی بعدی (فردا، هفته‌ی بعد یا ۳۰ روز بعد) خودش ساخته می‌شه.

## نکته‌ها
- کار تکراری «ماهانه» یعنی هر ۳۰ روز، نه دقیقاً هر ماه شمسی.
- اگه نوع یه برنامه رو از کلاس به کار عوض کنی، فقط روزهای بعدی (شروع‌نشده) عوض می‌شن؛ حضور و غیاب‌های قبلی تو آمار می‌مونن.
- متن پیام‌های کاری از همون متن‌های کلاس ساخته می‌شه (کلمه‌ی «کلاس» عوض می‌شه). اگه متنی رو خودت ویرایش کرده باشی، همین قانون روش اعمال می‌شه.
- هنوز «چک‌لیست داخل تسک» و «پیشنهاد الان سراغ کدوم برو» نیست؛ توی مرحله‌های بعدی میان.
