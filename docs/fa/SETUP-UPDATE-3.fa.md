# به‌روزرسانی ۳: هدف هر دسته، چالش به‌تفکیک دسته، اشتراک با پارتنر

این آپدیت **یه migration جدید داره** (`0008`).

## ۱) جایگزین کردن فایل‌ها
فایل zip رو Extract کن و محتوای پوشه‌ی `schedule-bot` رو روی `E:\schedule-bot` کپی کن (Replace). `node_modules` رو دست نزن.

## ۲) migration و آپلود
```powershell
npx wrangler d1 migrations apply schedule-bot-db --remote
npx wrangler deploy
```
باید ✅ کنار `0008_goals_and_scopes.sql` ببینی.

## ۳) تست
1. **هدف هر دسته:** توی کارت امروز، ⚙️ ← یه دسته رو باز کن ← «هدف روزانه / هفتگی (ساعت)» رو بنویس (مثلاً کار: ۳ و ۱۵). توی کارت امروز یه نوار پیشرفت برای هر دسته‌ای که هدف داره میاد (امروز X از Y • هفته X از Y، و ✓ وقتی رسیدی). توی تب آمار هم هدف هفتگی کنار هر دسته نشون داده می‌شه.
2. **اشتراک با پارتنر:** توی همون فرم دسته، سوییچ «پارتنر ببینه». اگه خاموشش کنی، پارتنر فقط «⏱ الان مشغوله 🤫» رو می‌بینه، بدون اسم دسته. ساعت اون دسته هم تو «امروز جمعاً»ی پارتنر حساب نمی‌شه.
3. **چالش:** پارتنر توی تب «چالش» یه بخش «📏 چی حساب بشه؟» داره: همه‌ی فعالیت‌ها، یا فقط یه دسته (مثلاً «کار»). پیشرفت و نتیجه‌ی شبانه فقط همون دسته رو می‌شمره. فقط دسته‌هایی که «پارتنر ببینه» روشنه قابل انتخابن. چالش‌های قبلی مثل قبل «همه‌ی فعالیت‌ها» حساب می‌شن.
4. **صفحه‌ی پارتنر:** به‌جای «درس می‌خونه» می‌نویسه «مشغوله» و اسم دسته‌های امروز رو نشون می‌ده.
5. **پیام‌ها:** تو متن پیام‌ها می‌تونی `{activity}` بنویسی؛ جاش اسم دسته‌ی امروز (یا آخرین دسته) می‌شینه. چهار پیام آماده هم با همین قابلیت اضافه شد. توی صفحه‌ی متن‌ها می‌تونی ویرایششون کنی.

## نکته‌ها
- پیام‌های آماده‌ی قبلی هنوز «درس خوندن» رو تو متنشون دارن (متنِ ثابت). اگه می‌خوای برای کار هم مناسب باشن، از صفحه‌ی متن‌ها `درس` رو با `{activity}` عوض کن.
- پیام‌هایی که به پارتنر می‌رن هیچ‌وقت اسم یه دسته‌ی «مخفی» رو نمی‌گیرن.
- «ساعت بیکاری» پارتنر همه‌ی دسته‌ها رو حساب می‌کنه (وقتی کار می‌کنی بیکار نیستی)، حتی اگه اون دسته مخفی باشه.
- اگه چالش روی «همه‌ی فعالیت‌ها» باشه و یه دسته مخفی داشته باشی، نوار پیشرفتش ساعت اون دسته رو هم جمع می‌زنه. اگه نمی‌خوای، چالش رو روی دسته‌ی مشخص بذار.
