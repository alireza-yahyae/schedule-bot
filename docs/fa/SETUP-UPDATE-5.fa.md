# به‌روزرسانی ۵: پومودورو هر دسته، استریک، عادت خودکار، گزارش هفتگی

این آپدیت **یه migration جدید داره** (`0010`).

## ۱) جایگزین کردن فایل‌ها
فایل zip رو Extract کن و محتوای پوشه‌ی `schedule-bot` رو روی `E:\schedule-bot` کپی کن (Replace). `node_modules` رو دست نزن.

## ۲) migration و آپلود
```powershell
npx wrangler d1 migrations apply schedule-bot-db --remote
npx wrangler deploy
```
باید ✅ کنار `0010_rhythm.sql` ببینی.

## ۳) تست
1. **پومودورو هر دسته:** تو کارت «تمرکز»، دسته رو انتخاب کن و یکی از زمان‌های ۱۵ / ۲۵ / ۴۵ / ۶۰ / ۹۰ دقیقه رو بزن. دسته‌ها زمان پیش‌فرض خودشون رو دارن: ⚙️ توی کارت امروز ← یه دسته ← «تمرکز (دقیقه)» و «استراحت (دقیقه)». وقتی دوره تموم شد، پیام «آفرین! … ☕ ۵ دقیقه استراحت کن» میاد، و زمانش به حساب همون دسته ثبت می‌شه (توی ساعت امروز، آمار هر دسته و استریک).
2. **استریک هر دسته:** زیر کارت امروز، برای هر دسته‌ای که ≥ ۲ روز پشت‌سرهم داشته باشه «📚 🔥 ۵ روز» می‌بینی. یه روز وقتی حساب می‌شه که دسته به **هدف روزانه‌اش** رسیده باشه، و اگه هدف نذاشته باشی به **۲۰ دقیقه**.
3. **عادت خودکار:** تب رشد ← عادت جدید ← «تیک خوردن» رو روی یه دسته بذار و حداقل دقیقه رو بنویس (مثلاً کار، ۶۰). هر روزی که اون دسته به اون زمان برسه، عادت خودش تیک می‌خوره (با خط‌چین نشون داده می‌شه). اگه خودت بخوای تیک بزنی، همون روزهای خودکار رو نمی‌شه دستی عوض کرد.
4. **گزارش هفتگی:** هر جمعه بعد از ساعت ۲۰ یه پیام میاد: مجموع ساعت‌ها با مقایسه‌ی هفته‌ی قبل، هر دسته با درصد تغییر و هدف هفته، پرکارترین و کم‌کارترین روز، استریک‌ها و تعداد تیک عادت‌ها. بی‌صدا فرستاده می‌شه. اگه دو هفته چیزی ثبت نشده باشه نمیاد. از تنظیمات ← «گزارش هفتگی» خاموشش می‌کنی.

## نکته‌ها
- دوره‌های تمرکز قبلی (قبل از این آپدیت) به حساب «درس» ثبت شدن و همون‌جا می‌مونن.
- پومودورو هنوز مثل قبل روی گوشی اجرا می‌شه (نه روی سرور)؛ اگه اپ رو ببندی و دوباره باز کنی، تایمرش ادامه داره و آخرش ثبت می‌شه.
- گزارش هفتگی رو برای تست زود نمی‌شه فرستاد؛ فقط جمعه‌ها بعد از ۲۰:۰۰ (به وقت تهران) خودکار میاد.
