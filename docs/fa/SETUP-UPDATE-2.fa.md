# به‌روزرسانی ۲: آمار هر دسته + ویرایش جلسه‌های قدیمی

این آپدیت **migration جدید نداره** (همون جدول‌های مرحله ۱ کافیه).

## ۱) جایگزین کردن فایل‌ها
فایل zip رو Extract کن و محتوای پوشه‌ی `schedule-bot` رو روی `E:\schedule-bot` کپی کن (Replace). `node_modules` رو دست نزن.

## ۲) آپلود
```powershell
npx wrangler deploy
```

## ۳) تست
1. تب **آمار**: یه بخش «⏱ فعالیت‌ها» اضافه شده (فقط وقتی جلسه‌ای ثبت کرده باشی).
   - برای هر دسته: ساعت این هفته، مقایسه با هفته‌ی قبل (▲ / ▼)، تعداد جلسه و میانگین هر جلسه.
   - نمودار «ساعت هر هفته» که ۸ هفته‌ی اخیر رو به تفکیک دسته نشون می‌ده.
2. تب **امروز**، کارت فعالیت: روی هر جلسه بزن تا **ویرایشش** کنی (دسته، ساعت شروع و پایان، استراحت). جلسه‌هایی که با `/study 90` ثبت شدن ساعت ندارن، فقط دسته و مدت‌شون عوض می‌شه.
3. دکمه‌ی «همه‌ی جلسه‌ها و ویرایش ›» زیر لیست: جلسه‌های ۳۰ روز اخیر به تفکیک روز. هر کدوم رو بزنی همون صفحه‌ی ویرایش باز می‌شه، و دکمه‌ی حذف هم همون‌جاست.

## نکته‌ها
- زمان جلسه‌ها تا ۶۰ روز قبل قابل ویرایشه. دسته‌ی جلسه‌های قدیمی‌تر رو هم می‌شه عوض کرد.
- اگه ساعت پایان بعد از نیمه‌شب باشه (مثلاً ۲۳:۳۰ تا ۰۱:۰۰) درست حساب می‌شه.
- بعد از هر ثبت یا ویرایش، آمار خودکار دوباره بارگذاری می‌شه.
- هنوز مثل قبل، چالش و هدف روزانه‌ی پارتنر همه‌ی دسته‌ها رو جمع می‌زنه. اون توی مرحله ۳ جدا می‌شه.
